# Security Policy

This repository hosts the Lumen plugin packages, which handle sense
data (camera, microphone, location, SMS) on the user's behalf once
wired into `lumen-app`. Security issues in a plugin's handling of that
data, or in its consent-gating logic, are treated seriously.

Do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting on this repository (repository page,
"Security" tab, "Report a vulnerability").

See the [organization-wide security policy](https://github.com/lumen-assistive/.github/blob/main/SECURITY.md)
for response times and scope.
